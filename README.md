# Say When Live downloads

Installers for **Say When Live 3.3.5 beta**.

Open **[Releases](https://github.com/Ringorocks25/say-when-live-downloads/releases)** and download one file.

## Mac

| File | Runs on |
| --- | --- |
| `SayWhenLive-3.3.5-beta-AppleSilicon-macOS13plus.dmg` | Apple silicon (M1/M2/M3/M4), macOS 13.4 or newer |
| `SayWhenLive-3.3.5-beta-AppleSilicon-macOS11-12.dmg` | Apple silicon, macOS 12.3–13.3 |
| `SayWhenLive-3.3.5-beta-Intel-macOS11.dmg` | Intel Macs, macOS 12 or newer |
| `SayWhenLive-3.3.5-beta-Intel-macOS12plus.dmg` | Intel Macs, macOS 12 or newer |

Apple menu → About This Mac shows chip and macOS version.

## Windows

The Windows installer will appear on the same Releases page when it is uploaded.
